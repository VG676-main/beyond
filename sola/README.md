# Sola

Тихий персональный планер. Сегодня, месяц, все планы, шесть тем. Работает в браузере и ставится на экран «Домой» как PWA. Планы остаются на устройстве, аккаунт не нужен.

## Локально

```bash
cd sola
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Файл `index.html` напрямую через `file://` не подойдёт: приложению нужны модули и HTTPS или localhost.

Проверка сортировки:

```bash
cd sola
npm test
```

## Экран «Домой» на iPhone

1. Откройте ссылку в **Safari** (не в Chrome и не из встроенного браузера мессенджера).
2. Нажмите **Поделиться**.
3. **На экран «Домой»**.
4. Имя: Sola. Иконка подставится сама.
5. Открывайте Sola с иконки, не из вкладки Safari.

Нужны `manifest.json`, иконки 180/192/512, apple touch icon, `viewport-fit=cover`, `theme-color` и service worker. Они уже в проекте. Стартовые экраны подготовлены для распространённых iPhone, от SE до 16 Pro Max. На моделях новее iOS может показать цвет фона `#F4EFE6`, если точного размера splash нет.

## Уведомления

Пока Sola открыта, напоминание приходит в выбранный момент. Если открыть приложение в течение двух часов после этого времени, пропущенное напоминание тоже придёт.

На iPhone системное разрешение работает только у приложения с экрана «Домой», с iOS 16.4. В обычной вкладке Safari кнопка включения может не получить разрешение. Это ограничение iOS.

Сигнал на заблокированном экране, когда Sola полностью закрыта, требует Web Push и отдельный сервер. В этой версии сервера нет, планы никуда не отправляются, и приложение не изображает, что такие фоновые сигналы уже работают.

Без точного времени напоминание привязано к якорю: утро 8:00, день 13:00, вечер 18:00, ночь 21:00, без времени 9:00. «За 1 день» означает предыдущий календарный день в то же время.

## Сортировка внутри дня

1. Точное время 00:00–04:59.
2. Точное время 05:00–11:59, затем планы «Утро».
3. Точное время 12:00–16:59, затем планы «День».
4. Точное время 17:00–20:59, затем планы «Вечер».
5. Точное время 21:00–23:59, затем планы «Ночь».
6. Планы без времени.

Новый план на 10:00 встаёт между 09:30 и 13:00. Если время убрать, план уходит вниз. «Утро» стоит после утренних часов и раньше дневных.

## Данные

Планы пишутся в IndexedDB (`sola` / store `plans`). Если IndexedDB недоступен, используется localStorage. Тема, язык и переключатель уведомлений лежат в `sola-settings`.

У записи есть `id` и `updatedAt`. Экраны ходят только в `createRepository()` в `js/store.js`, поэтому позже можно добавить аккаунт и слияние между устройствами, не переписывая интерфейс.
